# FreeCrawl PortableApps Builder — r6

A standalone GitHub Actions builder for **[FreeCrawl SEO Tool](https://github.com/kemalai/FreeCrawl-SEO-Tool)**. It downloads the latest published stable upstream tag without forking, compiles the desktop app on Windows, builds a genuine native x64 `FreeCrawlPortable.exe`, and prepares two packages for the **[Universal Portable Release Publisher v1.1.1](https://github.com/vhick/portable-release-publisher/releases/tag/v1.1.1)**.

## Important: two types of `.paf.exe` are possible

**Preferred:** The original, unmodified PortableApps.com Installer 3.9.22 generates a `.paf.exe`. Its vendor download is checked against a pinned SHA-256 and extracted using 7-Zip, without running the downloaded setup GUI. **New in r6:** The workflow looks for the vendor's real output filename across known directories and verifies the file's embedded FreeCrawl launcher and `appinfo.ini` before selecting it. The r5 script incorrectly assumed a specific file prefix and checked only `stage/`.

**Fallback:** If no valid official output is found, `installer/FreeCrawlPortable.nsi` is compiled with standard NSIS on the Windows runner. The result is a **real Windows executable installer** which installs the FreeCrawl PortableApps-style directory structure and keeps the user's `Data` directory during updates. **It is independently built, not generated by the PortableApps.com Installer, and not PortableApps.com-certified or officially approved.** The workflow always prints `Generated PAF engine: official` or `fallback`. The NSIS source is readable and does not use script-to-EXE wrappers, administrator rights, startup entries or registry modifications.

Neither installer path is considered complete until Windows installation, reinstallation, data-retention and executable tests pass. The final `.paf.exe` is **not** included in this builder ZIP; it must be built by GitHub Actions.

The builder generates these release assets (example for stable upstream 1.1.2):

```
FreeCrawlPortable_v1.1.2_r6_win64.zip
FreeCrawlPortable_v1.1.2_r6_win64.paf.exe
SHA256SUMS.txt
```

The files are published together, directly by your publisher, into your builder repository's GitHub Releases. No `actions/upload-artifact` or separate release publisher is used. Automatic release deletion remains disabled.

## GitHub Desktop: update your existing builder

1. Download and extract **FreeCrawl-PortableApps-Builder-Kit-r6.zip**.
2. Open your existing `FreeCrawl-PortableApps-Builder` in **GitHub Desktop**.
3. Select **Repository → Show in Explorer**.
4. Copy **all the contents** from r6 into the repository's top-level folder, replacing the r5 files, including the hidden `.github` directory. **Do not delete `.git`.**
5. In GitHub Desktop, enter `FreeCrawl Builder r6 - Detect official PAF and add tested NSIS fallback` and choose **Commit to main**.
6. Click **Push origin**.
7. On GitHub, open **Actions → Build FreeCrawl PortableApps ZIP and PAF Installer → Run workflow**.
8. Leave `publisher_ref` at `v1.1.1` and run the job.
9. When all tests pass, open the **Releases** page for the FreeCrawl builder repo and obtain the ZIP, PAF, and SHA-256 checksums.

For a new repository, use GitHub Desktop **File → New Repository**, create `FreeCrawl-PortableApps-Builder`, copy the builder files into it, commit and click **Publish repository**. Choose Public or Private yourself; the workflow never changes visibility. On GitHub, enable Actions and allow `contents: write` for release publishing.

## PortableApps installation

**PAF:** In the PortableApps Menu, choose **Apps → Install a New App**, and select the `.paf.exe`. If prompted for a destination, choose your **PortableApps parent folder** (for example, `X:\PortableApps`), not `X:\PortableApps\FreeCrawlPortable`. If the result uses the NSIS fallback, it offers a standard NSIS folder selection screen; it does not implement all official PortableApps.com Installer UI integrations. Both installers target the `FreeCrawlPortable` child folder.

**ZIP:** Extract the folder `FreeCrawlPortable` directly inside `X:\PortableApps`. Its root has the genuine compiled Windows EXE `FreeCrawlPortable.exe`, and `App/AppInfo/appinfo.ini` points to it. Refresh the PortableApps Menu to display the application.

**Updating:** Exit FreeCrawl completely and back up `Data`. Install the new PAF over the existing PortableApps **parent** folder. The installer is designed to replace `App` and `Other` and preserve existing `Data`. If updating from a ZIP manually, replace the program files but never delete or overwrite `Data`.

## Layout and portability

```
FreeCrawlPortable/
    FreeCrawlPortable.exe
    App/
        AppInfo/appinfo.ini
        AppInfo/installer.ini
        AppInfo/appicon.ico
        AppInfo/appicon_16.png ... appicon_256.png
        FreeCrawl/FreeCrawl SEO Tool.exe ...
        DefaultData/
    Data/
        Profile/ (Electron preferences, project databases and logs)
        Cache/ (Chromium cache)
        Temp/ (temporary application files)
    Other/Source/ (MIT license, C++ launcher and patch source)
    help.html
```

FreeCrawl uses Electron. The builder's guarded startup patch places `userData` and session data under `Data`, while the compiled C++ launcher sets child environment variables and redirects applicable caches. No scheduled tasks, autostart entries, registry persistence, drivers, services, elevation, or AV exclusions are added. Windows itself may still generate system logs, prefetch and recent-file traces. See `docs/SOURCE-AUDIT.md` for source details.

## Test gates and remaining limitations

- Uses `windows-2022`, manual `workflow_dispatch`, a single publishing job, concurrency protection, and an execution limit of 35 minutes.
- Retrieves the stable upstream release and validates the original source patch and compiled native x64 Windows executable.
- Verifies ZIP integrity, PortableApps metadata and icons, runs the app after moving folders, and checks persistent `Data`.
- Prefers official vendor Installer 3.9.22, verifies its SHA-256, inspects the real generated filename and embedded contents, and falls back only when no matching official installer exists.
- Compiles the fallback with the standard NSIS `makensis` tool, never an obfuscated executable wrapper. Refuses to modify existing `Data` and checks for a running FreeCrawl application before replacing application binaries.
- Installs the generated installer to a disposable Windows directory, checks the app files, inserts a sentinel into `Data`, reinstalls, and verifies the sentinel remains intact.
- Calls your shared `v1.1.1` publisher first in dry-run and then for the actual release. Publishes only after all checks succeed.

**Validation status at creation:** The user-provided r5 run confirms successful upstream FreeCrawl compilation, native launcher compilation, and ZIP creation. The r6 builder underwent static tests and packaging checks in Linux, but **the r6 Windows NSIS fallback and official output discovery have not yet been executed live**. Do not treat this as a certified PortableApps.com release or a proven successful Actions build before the new workflow passes.

### Failure troubleshooting

- **Official tool succeeds but no matching package:** r6 prints the candidate locations it checked; if none matches it switches to the independent NSIS fallback. The log will explicitly identify the selected engine.
- **NSIS compiler missing:** Check `makensis.exe` on the Windows runner; r6 fails visibly instead of silently downloading unsigned compilers.
- **NSIS compile fails:** Inspect the `Build PAF ...` step, particularly the compiler's stdout and stderr. The workflow will not publish invalid files.
- **Installation/updating fails:** Check `Install and upgrade generated PAF ...` and confirm the target folder is empty or the existing FreeCrawl application is fully exited.
- **FreeCrawl launch/relocation fails:** Check `Windows launch and folder relocation smoke test`. No release will be published unless the portably launched application passes.
- **Publisher error:** Verify the `publisher_ref` is `v1.1.1`. Changes to `vhick/portable-release-publisher` are **not required** for this revision.
